## How I build with AI agents

| Step | What happens |
| :--- | :--- |
| **Brief** | I say what I want in plain words, with the details that matter. |
| **Generate** | The agent writes and edits the code. |
| **Review** | I read the changes and run the app. |
| **Ship** | I fix what is wrong, then push it to GitHub. |
